# crisp_reproducibility

Reproducibility materials for analyses built on the [crisp](https://github.com/nitzanlab/crisp) package.

## Notebooks

| Notebook | Data |
|---|---|
| [`01_simulation_benchmark.ipynb`](01_simulation_benchmark.ipynb) | Synthetic data, generated in-notebook via `crisp.simulate_cyclic_processes`. |
| [`02_infection_preprocessing.ipynb`](02_infection_preprocessing.ipynb) | Spatio-temporally resolved single-cell atlas of the *Plasmodium* liver stage, deposited on [Zenodo](https://doi.org/10.5281/zenodo.7081863). |
| [`03_infection_crisp_analysis.ipynb`](03_infection_crisp_analysis.ipynb) | Same *Plasmodium* liver-stage atlas as `02` (preprocessed), [Zenodo](https://doi.org/10.5281/zenodo.7081863). |
| [`04_mouse_liver_zonation_circadian.ipynb`](04_mouse_liver_zonation_circadian.ipynb) | Mouse liver zonation scRNA-seq, GEO accession [GSE145197](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE145197). |
| [`05_liver_fibrosis_zonation.ipynb`](05_liver_fibrosis_zonation.ipynb) | Healthy and fibrotic liver MERFISH dataset, [Dryad](https://doi.org/10.5061/dryad.37pvmcvsg). |
| [`06_emt_tgf_dose_response.ipynb`](06_emt_tgf_dose_response.ipynb) | TGF-β-induced EMT scRNA-seq, GEO accession [GSE213753](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE213753). |
